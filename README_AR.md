# عالم المانجا — Android v0.3.0

تطبيق Android أصلي بلغة Kotlin بواجهة عربية RTL ومكتبة قصص تجريبية أصلية للمانجا والمانهوا. يستهدف الهواتف ويستخدم عناصر Android الأساسية دون مكتبات واجهة ثقيلة.

## الإضافات في v0.3.0
- حفظ المفضلة وقائمة الفصول المحفوظة وسجل القراءة محليًا حتى بعد إغلاق التطبيق.
- متابعة آخر فصل تمت قراءته من الصفحة الرئيسية.
- قارئ بفقرات عربية أصلية مدمجة، يعمل بلا إنترنت.
- تكبير وتصغير خط القارئ وحفظ الحجم المختار.
- وضع قراءة بلون دافئ، محفوظ بين مرات تشغيل التطبيق.
- الانتقال بين فصول العمل، ومشاركة اسم العمل أو الفصل.
- البحث بالعنوان والنوع والتصنيف والوصف.
- خمس وجهات تنقل: الرئيسية، البحث، المفضلة، المحفوظ، وسجل القراءة.
- استيراد عدة صور صفحات من الهاتف لكل فصل، وحفظ نسخ داخل مساحة التطبيق الخاصة وعرضها رأسيًا بلا إنترنت.
- حد الاستيراد: حتى 50 صورة في العملية الواحدة، وبحد أقصى 40 ميجابايت للصورة.
- تصميم مناسب للموبايل ولا يحتاج اتصال إنترنت أو صلاحيات تخزين واسعة.

## حدود النسخة بوضوح
- المكتبة الحالية تحتوي على 6 أعمال تجريبية و14 فصلًا بنصوص أصلية مكتوبة لهذا المشروع. ليست مكتبة ضخمة لأعمال تجارية معروفة.
- «حفظ دون إنترنت» يضيف فصول المشروع المضمّنة إلى قائمة يسهل الرجوع إليها، ولا يسحب محتوى من مواقع خارجية.
- لم يُضمّن ملف APK جاهز في هذه الحزمة، ولم نعتبر البناء ناجحًا دون تنفيذ بناء فعلي. استخدم GitHub Actions بالطريقة أدناه لإنتاج APK، ثم اختبره على جهازك.
- لإضافة صفحات أو فصول أعمال منشورة، اربط مصدرًا مرخصًا أو ملفات لديك الحق في توزيعها.

## إنتاج APK من الهاتف عبر GitHub
1. أنشئ مستودعًا فارغًا باسم `AlamAlManga`.
2. ارفع **محتويات** هذه الحزمة إلى جذر المستودع، بما في ذلك المجلد `.github`.
3. افتح تبويب **Actions** وفعّل GitHub Actions عند الطلب.
4. افتح سير العمل **Build Android APK** واضغط **Run workflow**، أو ارفع commit جديدًا.
5. بعد انتهاء العملية بنجاح، افتح التشغيل ثم **Artifacts** ونزّل `AlamAlManga-v0.3.0-debug-apk`.
6. فك الضغط وثبّت `app-debug.apk` على جهاز Android للاختبار.

## إصدار من GitHub Releases
بعد رفع المشروع، يمكن إنشاء tag مثل `v0.3.0` ودفعه إلى المستودع. سير العمل مهيأ لمحاولة إرفاق APK بصفحة Releases عند بناء tag.

## التفاصيل التقنية
- اسم الحزمة: `com.alamalmanga.app`
- `minSdk`: 23 (Android 6.0 أو أحدث)
- `compileSdk` و`targetSdk`: 35
- Kotlin 2.0.21، Android Gradle Plugin 8.7.3، Java 17
- APK من نوع Debug للاختبار، وليس إصدار Release موقعًا للنشر على Google Play.
